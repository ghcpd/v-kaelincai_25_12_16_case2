# MNIST Classifier v1.2 (Fixed)

## 📌 Project overview

This is the **fixed** version of the MNIST classifier project. It restores the missing pixel
normalization step that caused the regression in v1.1 and includes a full set of
tests that confirm the classifier now behaves correctly.

`MNISTClassifier` v1.2 expects normalized pixel values in the range `[0, 1]` and
produces correct predictions for the provided test images (digits 7 and 3).

---

## 🔧 Quick start (Windows / PowerShell)

```powershell
# From the project root (fast-oswe-1206/fixed_project)

# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate test data model and images
python generate_test_data.py

# 3. Run the test suite (should pass)
pytest tests/test_fixed.py -v
```

---

## ✅ Fix summary

* **Root cause:** During the v1.0→v1.1 upgrade the pixel normalization step (`img = img / 255.0`) was accidentally removed in `preprocess_image()`.
* **Fix:** Restored normalization and updated `VERSION` to `1.2.0`.

## 💡 Notes

**Important**: This project intentionally keeps the classifier implementation minimal and deterministic for the sake of the exercise. The model generated by `generate_test_data.py` is synthetic and designed to demonstrate the bug and the fix. It should not be used for production.

If you'd like to change the model or images, run `python generate_test_data.py` which will regenerate the `models/mnist_model.npy` and `data/` images.
